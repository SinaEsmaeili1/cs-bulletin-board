# CS Bulletin Board

A small website where students post and read notices about tutoring, clubs, events and opportunities.

This is a CSCI2690 student project prototype. It is the front-end demo: it runs entirely in the browser, with no server.

## Authors

- Sina Esmaeili


## How to run

Open `index.html` in a web browser. Nothing needs to be installed.

Notices you post are saved in that browser only. To go back to the six demo notices, add `?reset` to the end of the address of `index.html` and press Enter.
